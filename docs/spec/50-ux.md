# Manual-use UX and visual design

## Editing capabilities
- Piano roll with pitch, phoneme and parameter lanes; phonemes shown inside
  notes; scale/key highlighting from key_map; snap to grid, scale, or off.
- Phoneme timing lane: drag phoneme boundaries; adjust consonant strength
  and plosive onset prominence.
- Expression pad: an XY pad that sweeps two parameters (e.g. tension ×
  breathiness) live while a phrase loops; the result is written as curves.
- Separate vocal-mode selectors for pitch, timbre and pronunciation.
- Lyric entry: type a line and it flows across selected notes; paste a
  whole song and syllables auto-distribute.
- Import MusicXML (slurs, ties, multi-syllable words), MIDI, USTX, UST, DS.
  Voice-to-MIDI from a reference recording, optionally capturing its pitch curve.
- Take lanes for retakes (like comping in a DAW); one key to cycle takes.
- Analysis heatmap strip under the piano roll (e.g. red where pitch error
  exceeds 30 cents); click a hot spot to select the notes.
- Command palette (Cmd/Ctrl+K) listing every Op by name. Fully rebindable
  shortcuts.
- History panel with the branching undo tree, named checkpoints, and one-key
  A/B between any two checkpoints.
- Script Log panel (each action's Op and Python line) and a Python console.
- Macro recorder that saves actions as an editable Python script.
- Accessibility: full keyboard navigation, screen-reader labels (gpui-kit
  a11y), scalable UI, color-blind-safe palettes.

## Performance targets
- 120 fps scroll and zoom with 2,000+ notes and visible curves on an
  M-series Mac and a mid-range Linux GPU.
- UI interaction handling under 8 ms per frame.
- First audible preview of an edited phrase under 300 ms on a mid-range GPU;
  pitch-only edits (vocoder fast path) under 100 ms.

## Visual direction
A precise instrument, closer to Zed or a modern DAW than to a consumer app.
- Dark theme first (light theme must also work), neutral graphite surfaces,
  one accent color for selection and focus, a small fixed palette for track
  colors.
- Dense information with clear hierarchy: lane labels quiet, notes and
  curves prominent, the playhead and selection unmistakable.
- Notes: flat fills with a 1 px inner edge; lyric text inside the note in
  the UI font, phonemes in a smaller weight beneath.
- Curves: anti-aliased 1.5 px lines; the model-prediction layer drawn faint,
  the user delta drawn solid.
- Motion is functional only: under 120 ms, for panels and focus changes.

Do not use: glassmorphism or background blur; gradient-filled notes or
panels; drop shadows on notes; pill-shaped buttons; emoji as icons; rainbow
per-note colors; oversized rounded corners (keep radii at 4 px or below);
centered hero-style empty states with large illustrations; monospace text
for anything except numeric readouts.
